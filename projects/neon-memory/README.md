# Neon Memory Matrix

An accessibility-friendly browser memory game with a cyberpunk interface, animated cards, keyboard controls, and a reduced-motion mode.

## Run it

Open [`index.html`](./index.html) in any modern browser. No build step or dependencies are required.

## Controls

- Click or focus a card and press `Enter` or `Space` to flip it.
- Use `Tab` to move through the board.
- Press `R` to restart.
- Use the motion toggle to reduce animation.
